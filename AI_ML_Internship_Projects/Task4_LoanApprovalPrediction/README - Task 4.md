\# Loan Approval Prediction



\## Description

Predict whether a loan application will be approved using Machine Learning.



\## Problem Statement

Manual loan approval is slow and biased. This project automates the decision-making process using a classification model.



\## Tools \& Libraries

Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn | Joblib



\## Workflow

1\. Exploratory Data Analysis (EDA)  

2\. Handle missing values, categorical encoding, and scaling  

3\. Train and compare models: Logistic Regression, Decision Tree, Random Forest  

4\. Evaluation using Accuracy, Precision, Recall, F1-Score  

5\. Export trained model for deployment (.pkl)



\## Dataset

Included in `Dataset/` folder or download from \[Kaggle Loan Dataset](https://www.kaggle.com/datasets/altruistdelhite04/loan-prediction-problem-dataset)



\## How to Run

Open `LoanApproval.ipynb` in Jupyter Notebook or Colab.  

Run all cells sequentially.
