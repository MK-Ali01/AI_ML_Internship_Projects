\# Forest Cover Type Classification



\## Description

Predict forest cover type based on cartographic and environmental features.



\## Problem Statement

Identifying forest cover types is essential for ecological management and wildfire prevention. The project classifies forest areas into 7 types.



\## Tools \& Libraries

Python | Pandas | NumPy | Scikit-learn | XGBoost | Matplotlib | Seaborn



\## Workflow

1\. Exploratory Data Analysis (EDA)  

2\. Preprocessing, scaling, and categorical encoding  

3\. Training multiple classifiers: Logistic Regression, Random Forest, XGBoost  

4\. Feature importance analysis  

5\. Confusion matrix and model evaluation



\## Dataset

Included in `Dataset/` folder or download from \[UCI Covertype Dataset](https://archive.ics.uci.edu/ml/datasets/covertype)



\## How to Run

Open `ForestCover.ipynb` in Jupyter Notebook or Colab.  

Run all cells sequentially.
