\# Sales Forecasting



\## Description

Predict future sales based on historical data using regression models.



\## Problem Statement

Retail businesses require accurate sales forecasts for inventory and staffing. The goal was to predict next period’s sales using time-series regression.



\## Tools \& Libraries

Python | Pandas | Scikit-learn | Matplotlib



\## Workflow

1\. Time-series EDA  

2\. Feature engineering (day, month, lag values)  

3\. Training regression models (Linear Regression, Random Forest)  

4\. Visualize Actual vs Predicted sales  

5\. Evaluate model performance



\## Dataset

Included in `Dataset/` folder or download from \[Kaggle Walmart Sales Forecast](https://www.kaggle.com/datasets/)



\## How to Run

Open `SalesForecasting.ipynb` in Jupyter Notebook or Colab.  

Run all cells sequentially.
