\# Customer Segmentation



\## Description

Segment customers into groups based on spending behavior using K-Means clustering.



\## Problem Statement

Businesses need to understand customer behavior for targeted marketing. This project clusters customers by annual income and spending score.



\## Tools \& Libraries

Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn



\## Workflow

1\. Exploratory Data Analysis (EDA)  

2\. Feature scaling  

3\. K-Means clustering with optimal cluster selection (Elbow Method)  

4\. Cluster visualization and insights



\## Dataset

Included in `Dataset/` folder or download from \[Kaggle Mall Customer Dataset](https://www.kaggle.com/vjchoudhary7/customer-segmentation-tutorial)



\## How to Run

Open `CustomerSegmentation.ipynb` in Jupyter Notebook or Colab.  

Run all cells sequentially.
