\# Student Score Prediction



\## Description

Predict student exam scores based on study hours and other influencing factors.



\## Problem Statement

Educational institutions often seek data-backed insights to understand performance trends. The goal was to predict student scores using study hours and additional features.



\## Tools \& Libraries

Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn



\## Workflow

1\. Exploratory Data Analysis (EDA)  

2\. Correlation analysis and visualization  

3\. Linear Regression and evaluation  

4\. Feature selection and multiple feature testing  

5\. Model evaluation using R² score and MAE



\## Dataset

Included in `Dataset/` folder or download from \[UCI Student Dataset](https://archive.ics.uci.edu/ml/datasets/student+performance)
